# BlendBetter iOS

BlendBetter is a SwiftUI iOS app that helps users generate drink recipes based on selected or camera-detected fruits.

## Features
- Select up to 3 fruits manually
- Detect fruit from camera using Apple's Vision framework
- Automatically return detected fruit to Home view
- Generate recipes from backend API
- Stream recipe responses in real time

## Tech Stack
- SwiftUI
- AVFoundation
- Vision
- MVVM
- URLSession / SSE

## Current Status
MVP completed:
- Home fruit selection
- Camera preview and fruit recognition
- Auto-navigation back to Home
- Streaming recipe generation
